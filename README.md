# Projeto: Você Cairia?

Atividade curricular prática e controlada desenvolvida para a disciplina de Segurança da Informação.

## 📌 Alunas Desenvolvedoras
* Jhenifer Alves da Silva
* Júllia Ketrin Rambo Silva
* **Turma:** 3º A TI — IFRO

## 🎯 Objetivo
Analisar de forma quantitativa e anônima o impacto do senso de urgência em comunicações digitais e conscientizar a comunidade acadêmica sobre técnicas de Engenharia Social e Phishing.

## 🛡️ Ética e Privacidade
* **Sem dados pessoais:** Nenhuma senha, nome, e-mail ou IP é coletado.
* **Transparência:** O usuário é redirecionado imediatamente para uma página educativa assim que interage com o link.
* **Supervisão:** Atividade totalmente acompanhada pelo professor orientador e comunicada à direção.
